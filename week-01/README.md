# Week 1 — Cloud Fundamentals & Account Setup

My understanding is that the root user owns the AWS account and should be reserved for account-level tasks, not routine work. An IAM user is a separate identity with its own credentials and permissions, so daily administration can happen without using the root sign-in. Giving an IAM user AdministratorAccess makes it powerful, so those credentials need to be protected and used only when that level of access is needed. AWS is responsible for the security of the cloud, including the physical data centers and underlying infrastructure. I am responsible for security in the cloud, including access control, MFA, and the resources and data I configure. The shared responsibility model means security depends on both sides doing their part. MFA and a zero-spend budget alert add account protection and an early signal when charges begin.
